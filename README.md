# YouTube Thumbnails Generator

A professional YouTube thumbnail generator featuring 8 visually striking and cohesive thumbnails with modern, clean, and minimalistic design.

## Features

- **8 Professional Thumbnails**: Each designed for specific topics with symbolic imagery
- **Consistent Visual Style**: Modern, clean, and minimalistic design across all thumbnails
- **High Resolution**: 16:9 aspect ratio (1280x720) suitable for professional use
- **Soft Color Palettes**: Complementary colors that work well together
- **Bold Typography**: Readable titles with excellent contrast
- **Abstract Imagery**: Symbolic shapes relevant to each topic
- **Web-Based**: No complex dependencies, runs directly in browser

## Technical Specifications

- **Resolution**: 1280x720 pixels (16:9 aspect ratio)
- **Format**: PNG (downloadable)
- **Typography**: Segoe UI, Roboto, Helvetica, Arial
- **Colors**: CSS custom properties for easy theming
- **Responsive**: Adapts to different screen sizes

## Usage

### View Thumbnails
1. Open `index.html` in any modern web browser
2. View all 8 thumbnails in a responsive grid layout
3. Each thumbnail displays the title and subtitle prominently

### Download Thumbnails
1. Click the "Download PNG" button below each thumbnail
2. The high-resolution PNG will be saved to your downloads folder
3. Files are named descriptively (e.g., `marriage-relationships-thumbnail.png`)

### Customization
The design uses CSS custom properties, making it easy to modify:
- Colors can be adjusted in the `:root` section
- Typography can be changed in the `.title` and `.subtitle` classes
- Abstract shapes can be modified in their respective classes
